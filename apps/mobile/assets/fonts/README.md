# Fonts

Rubik, by Hubert and Fischer / Meir Sadan / Cyreal and the Rubik Project Authors
(https://github.com/googlefonts/rubik), licensed under the SIL Open Font License 1.1
(`OFL.txt`). The four files are static instances of the variable font, subset to
Latin, Latin Extended-A, Serbian Cyrillic and the app's punctuation with tabular
figures kept — see `scripts/make-fonts.py`. Registered by `App.tsx` under the
names `theme.ts` uses (`Rubik-400/500/700/900`); no style sets `fontWeight`.
